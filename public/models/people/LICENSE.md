# People models

Six rigged, animated people used by the children's game "স্বপ্নের মাঠ" (`/kids`, `src/game/three/dreamScene.js`).

- **Made by:** Quaternius, "Ultimate Animated Character Pack" (https://quaternius.com).
- **Licence:** CC0 1.0 Universal (public domain). Credit is not required but is given here.
- **Downloaded:** 30 October 2026, as GLB files from the CC0 mirror at
  `https://cdn.cinevva.com/assets/packs/quaternius/ultimate-animated-characters/`. They are unmodified.
- **Animations in each file:** Idle, Walk, Run, Jump, Victory, Defeat, SitDown, StandUp, PickUp, Walk_Carry,
  Run_Carry, Roll, RecieveHit, Death, Punch, Shoot_OneHanded, SwordSlash. The game uses only the peaceful ones.

| File | Used for |
| --- | --- |
| `Worker_Male.glb` | a working farmer (father) |
| `OldClassy_Male.glb` | an older farmer or grandfather |
| `Casual2_Male.glb` | a young man (Razib) |
| `Casual3_Female.glb` | a woman farmer (mother) |
| `Casual_Male.glb` | a boy (scaled down, larger head) |
| `Casual_Female.glb` | a girl (scaled down, larger head) |

Each character's skin, clothes and hair colours are set in code from `src/game/regions.js`, so one model serves
several people.
